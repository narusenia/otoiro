# otoiro 要件定義

総合音感トレーニング Web アプリ。初学者が「解説で学ぶ → その範囲だけ練習する」を段階的に進められることを最重要とする。

## 1. 前提・非機能

| 項目 | 決定 |
|---|---|
| アカウント | なし（MVP）。将来クラウド同期へ移行できるよう保存層を 1 モジュールに分離 |
| 保存 | IndexedDB（進捗・苦手データ・設定） |
| フレームワーク | Vite + React SPA（クライアントルーティング） |
| UI | shadcn/ui（preset `b1D0dxoG`）+ Tailwind |
| 配信 | Cloudflare Workers Static Assets。GitHub 連携 Workers Builds で push 時自動デプロイ、PR ごとにプレビュー URL。ドメインは当面 `*.workers.dev` |
| デバイス | スマホ優先（モバイルファースト）+ PC 対応 |
| PWA | 対応（vite-plugin-pwa）。初回読込後はオフライン動作、ホーム画面追加可 |
| 言語 | 日本語のみ。ただし i18n 基盤（文言キー化・ロケール別コンテンツディレクトリ）は用意 |
| テスト | 音楽理論ロジックのみ Vitest で単体テスト。UI は手動確認 |

## 2. 音

- 音色: **ピアノ（既定）/ サイン波** を設定で切替
- ピアノ: Salamander Grand Piano を短3度間隔の約30サンプル（約3MB）に間引き、自前配信（Tone.js Sampler）
- サイン波: Tone.js / Web Audio のオシレーター
- iOS の音声アンロック（初回タップで AudioContext 再開）に対応

## 3. 表記

- 音名: 既定は**ドレミ（固定ド）**。設定で `C D E` / `ハニホ` に切替
- 和音名: コード表記（C, Am, G7 …）を併記
- スケール度数・メロディ聴音のみ**移動ド**（ド = 主音）で回答

## 4. 学習構造

- **4 コース並列**: 音程 / 和音 / 五線譜 / 度数・メロディ
- 各コース = 単元の列。単元 = **解説（MDX）→ 練習ドリル**
- 単元は前提単元を指定可（例: 和音入門 ← 音程の3度合格）。前提を満たすまでロック
- 合格: 10 問中 8 問正解 → 次の単元を解放
- 苦手出題: 誤答した項目（例: 短3度と長3度）を重み付けで多めに出題
- 連続学習日数（streak）を表示
- 単元外の**自由練習モード**あり（解放済み範囲から出題）

### 4.1 コンテンツ

- 形式: MDX。`content/ja/<course>/<unit>.mdx`
- 本文中に音・譜面部品を埋込（例: `<Play notes="C4 E4" />`, `<Staff notes="..." />`, `<Keyboard highlight="..." />`）
- 単元の出題設定は frontmatter に記述
- 初版は Claude が起草（各コース 5〜8 単元程度）→ 利用者が校閲

## 5. トレーニング仕様

### 5.1 音程
- 範囲: 1 オクターブ内の全音程 + 複音程（9〜13 度）
- 提示: 上行 → 下行 → 同時（和声的）の順で解放
- 導入は完全5度・完全8度から
- 解説に有名曲の出だしによる連想を掲載
- 回答: 選択ボタン

### 5.2 和音
- 段階: 三和音 4 種（M / m / dim / aug）→ 七の和音 5 種（M7 / 7 / m7 / m7♭5 / dim7）→ 転回形の識別
- 回答: 選択ボタン
- 後続フェーズ: コード進行の聴き取り

### 5.3 五線譜リーディング
- 範囲: ト音記号・ヘ音記号、加線、臨時記号、調号。単音のみ（リズム読みは対象外）
- 描画: VexFlow
- 回答: 鍵盤 UI（押すと鳴る）

### 5.4 スケール度数 / メロディ聴音
- 各問の前にカデンツ（I–IV–V–I）で調を提示
- 度数: 調内で何番目の音かを移動ドで回答
- メロディ: 音高のみ、等音価（4分音符）3〜8 音。単元で音数・跳躍幅・使用度数を増やす
- メロディはルールベース自動生成（主音終止など）
- 回答: 鍵盤 UI。正解は VexFlow で譜面表示

## 6. 入力 UI

- 音程・和音: 選択ボタン
- 五線譜・メロディ: 1〜2 オクターブのスクロール可能な鍵盤 UI
- MIDI 入力: 対象外（後続候補）

## 7. デザイン

- shadcn ベースの落ち着いた UI
- **12 音 / 度数ごとに固有色**を割当て、鍵盤・譜面・正解表示で一貫使用（"otoiro" = 音色）
- ダークモード対応

## 8. 対象外（後続フェーズ候補）

- ログイン・クラウド同期
- 多言語コンテンツ
- コード進行聴き取り
- リズム読み・リズム聴音
- MIDI 入力
- 独自ドメイン
- E2E テスト
